# 练习公式键盘紧凑二级选择器设计

状态：已批准并实现
日期：2026-08-14

## 1. 目标

在不改变公式目录、LaTeX 输出和练习草稿协议的前提下，简化公式键盘导航：删除目录外的中文文本输入能力，并把二级标签按钮组收缩为紧凑下拉选择器，为公式键位释放稳定空间。

## 2. 已确认方案

采用视觉方案 A“行内小下拉”。一级分类仍使用当前直接切换方式，二级分类只显示当前选中项和展开箭头。

- 宽屏保留左侧一级分类栏；二级选择器放在公式内容区顶部。
- 窄屏保留顶部一级分类横向栏；二级选择器紧接在一级分类下方。
- 选择器左侧显示“二级”，触发区目标宽度约 154px、高度约 34px。
- 下拉菜单只列出当前一级分类所属的二级标签，不展示其他学科标签。
- 触发区和菜单项必须具有稳定 Key、选中态与中文无障碍语义。

不采用通栏下拉，因为桌面端占用过多横向空间；不采用折叠标签面板，因为展开会造成键盘高度跳变并增加额外状态。

## 3. 状态与交互

继续由 `PracticeFormulaKeyboard` 持有一级分类、二级标签、大小写和分页状态，不增加新的业务层状态。

1. 切换一级分类时，自动选中该分类的第一个二级标签，并将分页重置为第 1 页。
2. 从下拉菜单选择二级标签时，更新当前标签并将分页重置为第 1 页。
3. 点击右侧 `abc` 时，仍跳回“常用类—字母与数字”，并保持既有大小写状态。
4. 下拉菜单收起时只占一行，不改变内容网格、分页区和固定数字区的宽度规则。

## 4. 删除中文输入

“删除中文”明确指删除公式键盘的自由中文文本输入能力，不删除分类名称、键位名称或其他中文界面文案。

删除范围包括：

- “字母与数字”页中的“中文”键；
- `_showChineseInput` 异步流程；
- `_ChineseFormulaTextDialog` 及其内部状态；
- `insertPracticeFormulaText` 转义入口；
- 仅服务于上述能力的 Widget 与单元测试。

公式目录中的 26 个字母、4 个常用希腊符号、大小写切换和固定数字区均保持不变。删除“中文”键后，字母页网格从“2 个操作键 + 30 个目录键”变为“1 个操作键 + 30 个目录键”。

## 5. 布局边界

- 375px：一级分类可横向滚动，二级选择器保持单行且不溢出；内容区和数字区继续上下排列。
- 720px 与 1100px：一级分类保留左栏，二级选择器位于内容区顶部；内容区与右侧数字区的左右关系不变。
- 下拉菜单不得撑高公式键盘主体；菜单使用覆盖层展示。
- 内容分页仍按每页最多 20 项计算，切换标签后的页码不得沿用前一标签状态。

## 6. 数据与错误边界

本次只调整本地 Widget 交互，不新增接口、缓存、数据库字段、权限或外部请求。下拉选项直接读取 `practiceFormulaSectionsByPrimary`，显示文案读取 `practiceFormulaSectionLabels`，不得复制第二份分类数据。

当前二级标签始终属于当前一级分类；一级分类变化与二级标签重置必须在同一次 `setState` 中完成，避免出现短暂非法组合。空选项不应发生；若目录映射被错误配置为空，保持现有非空目录约束并在测试阶段暴露。

## 7. 测试与验收

- 一级分类按钮仍可直接切换，并只向下拉菜单提供所属二级标签。
- 下拉触发区显示当前二级标签；展开后可选择其他标签。
- 切换一级分类自动选择首标签，切换二级标签后分页回到第 1 页。
- “中文”键和中文输入弹窗均不存在。
- `abc`、大小写、公式模板、物理单位三页分页和固定数字区顺序保持正确。
- 375px、720px、1100px 均无布局溢出。
- 运行 `flutter analyze lib/features/practice_assessment/presentation`、`flutter analyze test/features/practice_assessment` 与 `flutter test test/features/practice_assessment`。

## 8. 非目标

- 不改变一级分类样式。
- 不增加搜索、收藏、最近使用或下拉筛选。
- 不调整键位目录、分页大小或 LaTeX 插入行为。
- 不修改后端与远程判题逻辑。
