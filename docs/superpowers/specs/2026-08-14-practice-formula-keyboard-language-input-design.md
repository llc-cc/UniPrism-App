# 练习公式键盘字母与中文输入设计

## 目标

在不改变练习草稿和后端答案协议的前提下，为填空题公式键盘提供完整的 26 个英文字母、大小写切换与公式中文本片段输入。

## 交互

- 左侧分类增加“字母”，“更多”继续保留逻辑和数集符号。
- 右侧首行 `abc` 是字母页快捷键：首次点击打开字母页，在字母页再点击则在 `abc` 与 `ABC` 之间切换。
- 字母页使用 7 列紧凑网格，同屏展示 26 个字母；窄屏也不增加第二层翻页。
- “中文”入口放在字母页首个键位，点击后弹出原生 `TextField`，交给系统中文输入法处理。
- 点击“插入”后，将非空中文作为 `\text{...}` 文本节点插入当前公式光标；取消或空内容不改变答案。

## 边界

- 纯文字解题过程继续使用现有普通文本框；本入口只解决填空答案中的公式与中文混排。
- 插入前转义 TeX 特殊字符，防止用户文本破坏公式结构。
- 不新增依赖、网络请求、数据表或后端字段。

## 验收

1. `abc` 页可见 a–z 全部 26 个字母。
2. 切换后可输入 A–Z，再切换可回到小写。
3. 中文弹窗可取消；确认“最大值”后公式值包含 `\text{最大值}`。
4. 宽屏和 375px 窄屏无布局溢出。
