# 练习公式键盘字母与中文输入设计

## 目标

在不改变练习草稿和后端答案协议的前提下，为填空题公式键盘提供完整的 26 个英文字母、大小写切换与公式中文本片段输入。

## 交互

- 左侧分类增加“字母”，“更多”继续保留逻辑和数集符号。
- 右侧首行 `abc` 只是字母页快捷入口，连续点击不再切换大小写。
- 字母页使用 7 列紧凑网格，第一个键位为手机键盘风格的 `⇧ 大写`，第二个键位为“中文”，其余同屏展示 26 个字母，刚好形成 4 行。
- `⇧ 大写` 默认使用普通键样式并显示小写字母；点击后键位高亮且 26 个字母全部变为大写；再点击恢复小写。小写状态不显示“小写”文案。
- “中文”键打开并自动聚焦原生 `TextField`，指定普通文本键盘、候选词与自动纠错，交给系统中文输入法处理。手机端由操作系统展示 26 键拼音和候选词；桌面 Web 端使用电脑已安装的输入法，页面不伪造候选词。
- 点击“插入”后，将非空中文作为 `\text{...}` 文本节点插入当前公式光标；取消或空内容不改变答案。

## 边界

- 纯文字解题过程继续使用现有普通文本框；本入口只解决填空答案中的公式与中文混排。
- 插入前转义 TeX 特殊字符，防止用户文本破坏公式结构。
- 不新增依赖、网络请求、数据表或后端字段。

## 验收

1. `abc` 页可见 a–z 全部 26 个字母。
2. `⇧ 大写` 键高亮后可输入 A–Z，再点击可回到小写；`abc` 不修改该状态。
3. 中文输入框配置为系统普通文本输入并可取消；确认“最大值”后公式值包含 `\text{最大值}`。
4. 宽屏和 375px 窄屏无布局溢出。
