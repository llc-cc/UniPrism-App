# 练习公式键盘折叠式二级导航设计

状态：已批准，待实施
日期：2026-08-14

## 1. 目标

修正公式键盘二级导航的位置关系：二级标签不再占用公式内容区顶部，而是作为所属一级分类的可折叠子项。保留已完成的中文自由输入删除、公式目录、分页、LaTeX 输出和草稿协议。

## 2. 已确认布局

采用方案 A。

- 宽屏：左侧一级分类栏改为单开手风琴。当前展开一级项的二级标签直接显示在该一级项下面；其他一级项保持收起。
- 窄屏：保留可横向滚动的一级分类栏；当前一级分类的二级折叠面板位于一级栏下一行，不使用下拉菜单。
- 公式内容区从第一行直接显示键位，不再显示“二级”文案、下拉触发区或覆盖层菜单。
- 一级项带展开/收起箭头，二级项使用缩进、较小高度和明确选中态表达父子关系。

宽屏示意：

```text
常用类 ▼
  字母与数字
  常用符号
  常用模板
数学类 ▶
物理类 ▶
```

## 3. 状态与交互

`PracticeFormulaKeyboard` 继续持有一级分类、二级标签、分页和大小写状态，并新增一个仅用于展示的折叠布尔状态。

1. 初始为“常用类”展开、“字母与数字”选中。
2. 点击另一个一级分类时，切换到该分类、选中其首个二级标签、重置到第 1 页并展开其二级项。
3. 再次点击当前一级分类时，只收起或展开二级项，不改变当前二级标签、分页或公式内容。
4. 点击二级标签时切换内容并重置到第 1 页，折叠面板保持展开。
5. 点击 `abc` 时回到“常用类—字母与数字”，展开二级项并保持既有大小写状态。
6. 任一时刻最多只有当前一级分类的二级项可见，不允许出现跨分类二级项。

## 4. 响应式边界

- 375px：一级分类保持横向滚动；二级项在下一行横向滚动，收起后该行完全移除；内容区和数字区上下排列且无溢出。
- 720px 与 1100px：左侧导航栏包含展开的二级项；公式内容区与固定数字区继续左右排列。
- 宽屏导航栏宽度可在现有 112px 基础上小幅增加，以保证二级中文标签不截断，但不得挤压 720px 下的公式键位区。
- 折叠只改变导航自身高度，不改变右侧数字区宽度、内容网格列数或分页大小。

## 5. 数据与错误边界

一级与二级关系只读取 `practiceFormulaSectionsByPrimary`，文案只读取现有标签映射，不复制目录数据。一级切换与首个二级标签重置必须在同一次 `setState` 中完成；单纯收起当前一级项不得触发业务状态重置。

本次不新增接口、缓存、数据库字段、权限或外部请求，不修改后端远程练习协议。

## 6. 测试与验收

- 宽屏初始二级项直接位于“常用类”下方，公式区顶部不存在下拉选择器。
- 切换一级分类后只显示其二级项并自动选择首项；再次点击可收起，再次点击可展开。
- 窄屏使用“横向一级栏 + 下一行折叠二级面板”，不出现旧二级下拉或布局溢出。
- 二级切换继续重置分页；`abc`、大小写、公式模板、三页物理单位和固定数字区行为不变。
- 375px、720px、1100px 的导航、内容和数字区关系稳定。
- 运行相关静态检查与 `flutter test test/features/practice_assessment`。

## 7. 非目标

- 不改变公式键位目录和 LaTeX 插入策略。
- 不新增多级树、搜索、收藏、最近使用或允许多个一级分类同时展开。
- 不恢复中文自由文本输入。
- 不修改后端和数据库。
