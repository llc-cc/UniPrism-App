# 练习填空题内嵌公式答案框设计

## 目标

填空题题干中的连续下划线是答案位置。学生点击该位置后，使用现有数学公式键盘输入；答案应直接排版在题干空格内，不再在题干下方显示重复的大型答案输入框。

## 交互与布局

- 第一版支持当前题库的单空填空题。
- 将题干按首个连续下划线占位符拆成前文、内嵌公式框和后文。
- 内嵌框保持单行紧凑尺寸，获得焦点时显示紫色边框，并在题目下方展开现有公式键盘。
- 输入的数字、分数、根式和数学符号在内嵌框内按 LaTeX 即时排版。
- 题干没有合法占位符时保留兼容降级：在题干后追加内嵌公式框，保证仍可作答。
- 公式格式错误在输入区域附近展示，不清空学生草稿。

## 数据边界

继续复用 `MathFieldEditingController` 和现有 `PracticeDraft.answer`。组件只对外读写 LaTeX 字符串，因此切题恢复、防抖保存、提交判题与后端协议保持不变。

## 验证

- Widget 测试确认下划线被替换为题干内嵌输入框，页面不存在第二个大型答案框。
- Widget 测试确认点击内嵌框可展开键盘，输入分数后草稿得到对应 LaTeX。
- 回归验证切题恢复、非填空题输入和公式键盘既有测试。
- 运行目标 Flutter 测试、静态分析和 Web 构建后重新启动测试页面。

## 第一版限制

多空题需要将单字符串答案升级为有序答案集合，不在本次展示优化中提前引入。
