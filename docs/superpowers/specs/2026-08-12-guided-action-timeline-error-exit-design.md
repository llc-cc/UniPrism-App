# 引导课堂任务时间线与失败退出设计

日期：2026-08-12

## 1. 目标

修正 1.2 AI 探索课堂的两个交互问题：

1. 当前教学任务必须出现在最新一轮“学生消息 → AI 老师回答”之后，不能固定置于整条时间线顶部，也不能形成看似重复的任务卡。
2. 必做练习在正常状态下仍不可跳过；只有网络提交失败后，练习弹窗才显示关闭入口，让学生能够退出被阻塞的弹窗并回到课堂处理错误。

## 2. 范围

本次只调整 Flutter 展示与弹窗交互，不修改后端教学状态机、题目、证据、幂等键或会话协议。

涉及：

- 课堂时间线中当前教学动作的渲染位置；
- 练习失败弹窗的关闭行为；
- 对应 Widget 回归测试。

不涉及：

- 历史节点数据结构；
- 服务端素材、微测或掌握判定；
- 练习提交失败后的自动重试策略；
- 视觉主题的整体重做。

## 3. 课堂时间线设计

采用“当前动作作为时间线最后一项”的方案。页面阅读顺序固定为：

```text
课堂标题与探索路径
→ 历史轮次
→ 最新学生消息
→ 最新 AI 老师回答
→ 当前教学任务（素材、微测或反思）
→ 输入框
```

`_GuidedTeachingActionPanel` 不再放在 `_StudentLearningTimeline` 之前，而是追加到由当前路径生成的时间线末尾。当前动作仍是唯一可交互实例；历史素材继续由各自的只读轮次卡展示。

这一方案保留既有状态与组件边界：

- 服务端快照继续决定当前阶段和动作；
- `_ExplorationTurnCard` 只展示已发生的对话轮次；
- `_GuidedTeachingActionPanel` 只展示尚待学生执行的当前动作；
- 互动素材仍从当前动作关联的 `materialUsageId` 解析，不复制到历史卡。

## 4. 练习失败退出设计

正常打开必做练习时：

- 不显示关闭按钮；
- 点击遮罩不能关闭；
- 浏览器返回或系统返回不能关闭；
- 学生必须提交完整的推理和答案。

当提交请求失败后：

- 保留推理与答案草稿；
- 保留“重试提交”按钮及原幂等请求；
- 弹窗标题右侧显示 `X`；
- 点击 `X` 只关闭弹窗，不提交新答案、不推进教学阶段；
- 回到课堂后，页面错误面板继续显示失败原因与“重试”，当前会话快照不被清除。

遮罩仍保持不可点击退出，避免学生误触；失败后的退出必须通过明确的 `X` 完成。

## 5. 错误与数据边界

- `X` 不代表取消服务端已收到的请求；它只结束当前弹窗展示。
- 控制器继续保存首次失败操作的幂等重试信息，页面级“重试”沿用现有逻辑。
- 关闭弹窗不创建证据、不改变练习答案、不切换题目。
- 后端恢复后，学生可以使用页面级重试继续原请求；若重新打开题目，仍以最新服务端快照为准。

## 6. 验收标准

### 时间线

- 页面顶部不再先显示当前教学任务。
- 最新学生消息之后先显示对应 AI 回答，再显示当前教学任务。
- 当前教学任务只有一个可交互实例。
- 移动位置不改变素材提交、微测和反思行为。

### 失败弹窗

- 初始练习弹窗找不到关闭 `X`。
- 提交失败后可以看到关闭 `X`。
- 点击 `X` 后弹窗消失，课堂页面仍存在。
- 页面仍显示错误信息和重试入口。
- 关闭动作不会新增练习请求或推进教学阶段。
- 失败弹窗中的“重试提交”继续复用同一幂等键。

## 7. 测试计划

在 `live_tree_page_test.dart` 中增加或调整 Widget 测试：

1. 用控件纵向位置断言当前任务位于最新 AI 回答之后。
2. 断言课堂时间线只包含一个当前任务面板。
3. 断言未失败时没有关闭按钮，遮罩和返回仍不可退出。
4. 模拟练习提交失败，断言草稿、重试按钮和关闭 `X` 同时存在。
5. 点击 `X`，断言练习弹窗关闭、课堂和错误面板仍存在，提交调用次数不增加。
6. 保留既有同幂等键重试测试。
