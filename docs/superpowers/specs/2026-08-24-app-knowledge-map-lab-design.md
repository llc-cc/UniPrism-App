# App 高中数学知识图谱实验页设计

## 目标

在 Flutter App 的 Web 开发环境中提供高中数学知识图谱实验页，用于验证三级目录的展示、导航和响应式交互。页面沿用 Figma 的浅色画布、左侧目录与节点卡片语言，但不依赖后端即可验收。

## 数据边界

- 一级展示 9 个高中数学模块及知识点、分支统计。
- “预备知识与不等式”“函数”接入本地知识图谱的完整二级主题和三级知识点。
- 其余模块只展示一级概览并标注“后续接入”，避免伪造尚未实现的下钻内容。
- 本期数据来自 `D:\ywkeji\高中数学知识图谱\index.html` 的 `DATA.mods` 与 `DATA.kps`，不发起外部请求。

## 交互

1. 默认选中“预备知识与不等式”，画布展示一级模块节点及二级主题节点。
2. 点击左侧模块切换一级选中状态；具备数据的模块刷新二级主题，未接入模块显示明确空态。
3. 点击二级主题进入三级视图，展示所属知识点；顶部面包屑同步增加主题层级。
4. 点击面包屑模块或“返回上一级”回到二级视图。
5. 点击知识点打开详情面板，保持当前层级和选中路径不丢失。
6. 桌面端为左侧模块栏加右侧画布；窄屏将模块栏变为横向列表，节点纵向排列且页面可滚动。

## 接入位置

- 新增开发路由 `/knowledge-map-lab`，便于从 `localhost:5174` 直接验收。
- 将 `/dialogue-exploration-lab` 侧栏的“功能区 B”命名为“知识图谱”并接入同一页面。
- 不替换已有对话探索测试入口，也不修改正式生产路由。

## 验收标准

- 1440 像素宽度下可完成模块 → 主题 → 知识点 → 详情的完整操作。
- 390 像素宽度下无横向溢出，模块可横向选择，知识点可纵向浏览。
- 前两个模块分别显示 8/2 与 17/3 的统计，三级知识点数量与本地图谱一致。
- Flutter Widget 测试覆盖默认态、下钻、返回、未接入空态和窄屏布局。
