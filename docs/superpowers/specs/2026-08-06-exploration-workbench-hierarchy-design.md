# 1.2 探索课堂层级与回答质量设计

## 目标

以用户提供的图二为视觉基准，把会话页调整为主次清楚的桌面学习工作台，并让 Mock 阶段的回答也能直接回应学生当前问题。

## 已确认方案

- 顶部只保留课题、节点进度、剩余时间、导出与结束操作，形成全局学习状态。
- 桌面端左侧约 70% 是唯一主任务区：当前探索方向、学生问题、AI 直答、可操作素材、具体反问、输入框。
- 右侧约 30% 同时展示“我的探索路径”“章节知识结构”“探索概览”，不再让用户通过切换才能看到另一棵树。
- 普通历史节点降噪，当前节点用紫色描边突出；树的连线、状态点和统计形成次级信息层。
- Mock 回答遵循“先直答—再验证—最后具体反问”，针对负数乘法分别处理核心问题、方向翻转、不理解和分配律验证。
- 素材按轮次与问题选择，避免每轮重复插入同一组素材；交互素材继续保持可操作。

## 边界

- 不接入正式知识库，不新增外部依赖或生产数据表。
- 不改变现有会话、分支、回溯、记忆候选和导出接口。
- 手机端继续使用当前路径 + 弹层树结构，本轮重点验收浏览器桌面端。

## 验收

- 1280px 及以上同时看到主对话、个人思维树、章节知识树和探索统计。
- 顶部能看到节点进度与剩余时间，当前探索方向在对话首屏可见。
- “为什么两个负数相乘会得到正数”“为什么要翻转向右”“不懂”得到不同且直接相关的回答与反问。
- Flutter 组件测试、模块分析、后端教学引擎测试和 TypeScript 类型检查通过。
