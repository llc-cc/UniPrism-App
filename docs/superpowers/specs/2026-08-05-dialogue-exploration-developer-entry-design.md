# 1.2 对话探索主应用测试入口设计

## 目标

将已经独立实现的 1.2 对话探索实验室接入当前 UniPrism 主应用，让测试者无需切换 Flutter 入口文件或安装另一份演示应用。

## 用户路径

`兴趣探索首页 → 开发者工具 → 1.2 对话探索实验室`

实验室继续提供三个 Mock 场景：

- 二次函数教学端，用于验证按学生掌握程度调整讲解；
- 不等式练习端，用于验证错误分支、诊断、回退和复述；
- 咖啡店 Business Model Demo，用于验证多层发散和多形态素材。

## 实现边界

- 只在现有 `DeveloperToolsPage` 列表增加一个导航项，不新增首页卡片，不改变正式学生动线。
- 导航目标直接复用 `ExplorationLabPage`，不复制 1.2 页面或业务逻辑。
- 独立入口 `dialogue_exploration_demo.dart` 保留，供模块隔离调试使用。
- 本次不接正式知识库、模型、学生档案、3.3 白板或持久化服务，仍明确展示 Mock 标记。
- 主应用运行后通过热重启即可看到入口，不需要再启动第二个 Flutter 应用。

## 错误与数据处理

入口本身不发起网络请求，也不新增本地缓存、数据库或权限。1.2 现有 Mock 数据只保存在当前进程内，退出应用后清除。

## 验证

- Widget 测试确认开发者工具页出现唯一的 1.2 入口；
- 点击入口后显示“1.2 对话探索实验室”和三个测试场景；
- 运行 1.2 模块测试与仓库全量 Flutter 测试；
- 对相关 Dart 文件执行静态分析。
