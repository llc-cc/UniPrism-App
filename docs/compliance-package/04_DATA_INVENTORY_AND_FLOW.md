# 04 个人信息清单与数据流

> 状态：初稿，需根据后端、SDK 和云资源真实实现补齐。

## 1. 数据最小化原则

Agent 个性化推荐首版只应使用：

- 用户主动选择的兴趣；
- 已有测评产生的粗粒度兴趣标签；
- 内容展现、打开、有效阅读、收藏和不感兴趣；
- 用户主动设置的订阅、频率和静默时段；
- 设备推送 Token；
- 必要的账号和安全日志。

首版默认不使用精确位置、通讯录、相册、麦克风、学校、班级、详细成绩、健康或心理信息。

## 3. 数据流

```text
Flutter
  ├── 用户输入、兴趣选择、订阅确认
  └── 行为事件、设备 Token
        ↓ TLS
业务后端
  ├── 身份鉴权
  ├── 用户画像与订阅
  ├── 数据最小化和脱敏
  ├── 外部搜索 Provider
  └── Agent Gateway
        ├── 阿里云百炼（最小化模型输入）
        ├── 内容合作方（仅搜索参数）
        └── 推送服务商（用户/设备投递标识）
```

## 4. Agent 数据规则

- 不把手机号、证件号、学校、详细测评原始答案传给搜索平台；
- 模型只接收完成当前任务必需的兴趣摘要；
- 不在 Prompt 中嵌入完整用户数据库记录；
- 不允许模型查询其他用户；
- Agent 工具调用绑定当前登录用户；
- 模型日志不记录 API Key、Token 和完整个人敏感信息；
- 外部搜索词避免包含可识别用户的信息；
- 使用境外模型前单独开展数据出境评估。
