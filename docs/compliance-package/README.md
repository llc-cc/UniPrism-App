# 万有棱镜 Agent 功能备案与合规准备包

> 状态：内部准备稿  
> 版本：v0.1  
> 日期：2026-07-22  
> 使用范围：产品、技术、法务、运营及外部主管部门预咨询

本目录用于提前收集 App 备案、新闻业务定性、算法备案、生成式 AI 应用登记、安全评估、个人信息保护和外部内容合作所需材料。

这些文件是准备模板，不是主管部门正式表单，也不构成法律意见。提交前应根据真实上线版本填写，并由运营主体负责人、产品、技术和法务共同确认。

## 当前可直接开展的工作

- 填写企业和 App 基础信息；
- 固定正式 App 名称、包名、Bundle ID、签名和域名；
- 核查域名 ICP 与 App 备案状态；
- 使用业务说明书向属地网信办进行新闻业务定性咨询；
- 向知乎、小红书和阿里云提交合作咨询；
- 建立内容来源权利矩阵；
- 完成数据清单、数据流和个人信息影响评估初稿；
- 完成算法机制和安全自评估初稿；
- 使用模拟或自有内容开发内部 Agent MVP；
- 建立每次发布前的合规变化评估。

## 使用流程

1. 先填写 `01_BASIC_INFORMATION.md`，不确定项不要猜测；
2. 由产品和技术确认 `02_PRODUCT_AND_AGENT_DESCRIPTION.md`；
3. 未进入 `03_CONTENT_SOURCE_RIGHTS_MATRIX.md` 且状态不是“已批准”的来源不得接入生产；
4. 根据真实代码、SDK 和云资源填写 `04_DATA_INVENTORY_AND_FLOW.md`；
5. 将 `05`、`06` 用于新闻业务预咨询；
6. 产品功能稳定后完成 `07`，再与属地网信部门确认提交方式；
7. 立即发送 `08` 中的合作申请；
8. 每次上线都填写一份 `09` 并归档。

## 文档控制

- 每份材料必须标注版本、日期和负责人；
- 不覆盖历史提交版本；
- 主管部门、云厂商和平台回复以 PDF、邮件或工单截图留档；
- 线上实现必须与申报材料一致；
- 主体、包名、域名、模型、算法、数据和内容来源变化时重新评估。
