# 05 内容分类、审核、推送与撤回规则

## 1. 分类标准

### A：自有教育内容

测评说明、专业介绍、课程、学习任务、自有编辑原创知识。

处理：内部内容审核通过后可展示和推荐。

### B：外部非新闻知识

专业体验、学习方法、大学生活、工具教程、竞赛经验和职业访谈。

处理：来源权利允许展示、AI 和推送后方可进入对应流程；观点需标明来源，不作为政策事实。

### C：官方通知

学校、竞赛组织方或机构发布的活动报名、课程安排和服务通知。

处理：核验官方身份、适用地域、人群、截止日期和变更状态。

### D：新闻信息

涉及政治、经济、军事、外交等社会公共事务，以及社会突发事件的报道或评论，包括相应教育政策和社会热点。

处理：进入互联网新闻信息服务许可、合法稿源和持证合作链路。许可结论不明确时禁止公开新闻推送。

### E：高风险内容

招生录取、考试政策、医疗心理、未成年人伤害、犯罪、自杀自残、社会突发事件、来源冲突和模型不确定内容。

处理：必须人工审核；不适合个性化推送的内容直接禁止推送。

## 2. 机器规则

机器规则至少检查：

- 来源是否启用且授权有效；
- 是否允许展示、AI 分析和推送；
- 是否为新闻或高风险内容；
- 日期、数字、主体、地域和适用人群；
- 是否过期、撤回或已经推送；
- 是否与同一事件重复；
- 是否命中用户屏蔽主题；
- 是否处于静默期或超过频率；
- 是否涉及未成年人不适宜内容；
- AI 标识和来源信息是否完整。

## 3. 人工审核

审核页面需并排展示：

- 原标题、原链接和来源；
- 原始授权摘要或证据段落；
- AI 摘要、标签和推荐语；
- 日期、数字、机构和适用范围差异；
- 内容权利；
- 新闻/风险分类；
- 目标用户和推送文案；
- 模型、Prompt 和策略版本。

审核状态：

```text
DRAFT
→ MACHINE_REVIEWED
→ HUMAN_REVIEW_REQUIRED
→ APPROVED / REJECTED
→ SCHEDULED
→ SENT
→ DELIVERED / FAILED
→ RETRACTED / EXPIRED
```

## 4. 推送规则

- 由用户确认订阅后才能发送；
- 默认每天最多一次，每次最多三条；
- 默认静默期 22:00～07:30；
- 推送文案不展示敏感画像；
- 不使用恐吓、焦虑和夸大标题；
- 新闻许可不明确时禁止新闻通知；
- 高风险内容不能仅凭模型自动推送；
- 发送前再次校验来源权利、审核状态和用户设置。

## 5. 撤回与更正

发现原文删除、授权失效、摘要错误或政策更正时：

1. 立即停止未发送任务；
2. 标记内容 `RETRACTED`；
3. App 详情页显示撤回/更正说明；
4. 必要时向已接触用户发送更正站内信；
5. 保存原因、责任人、处置时间和影响范围；
6. 更新模型评测集和审核规则。

## 6. 抽检指标

- 未授权内容上线数量：0；
- 新闻和高风险人工审核覆盖率：100%；
- 日期、数字、主体和政策范围重大错误：0；
- 重复推送率：接近 0；
- 静默期违规：0；
- 来源和 AI 标识完整率：100%。
