## 3. 技术执行字段

权利结果应转换为生产配置，而不是只保留在合同中：

```json
{
  "sourceId": "zhihu",
  "status": "pending",
  "allowDisplayTitle": false,
  "allowDisplayExcerpt": false,
  "allowCache": false,
  "allowFullText": false,
  "allowImage": false,
  "allowAiProcess": false,
  "allowEmbedding": false,
  "allowPersonalizedRecommendation": false,
  "allowPush": false,
  "mustLinkBack": true,
  "retentionDays": 0,
  "validTo": null
}
```

生产任务每次展示、模型分析和推送前都重新检查 `status`、有效期及对应权利字段。

## 4. 来源审核问题

- 来源是否具有所需许可或资质？
- 发布账号是否属于实际授权范围？
- 用户原创内容的作者权利如何获得？
- 是否允许商业展示和衍生处理？
- 是否允许将内容传给第三方模型？
- 模型服务商是否会保存或用于训练？
- 是否允许通知推送？
- 授权终止后历史缓存如何处理？
- 原内容删除、更正或投诉后如何通知？
- 是否限制地域、设备、用户量和调用量？
