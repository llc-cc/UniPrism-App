## 1. 产品概况

万有棱镜是一款面向学生及相关教育参与者的兴趣探索、专业体验和成长辅助 App。现有核心功能包括兴趣测评、专业体验、个人报告、消息通知和账号管理。

拟新增“Agent 个性化知识检索与订阅”功能。用户可通过对话表达关注的专业、学科、竞赛、学习方法或教育话题，Agent 在获得授权的内容源中检索相关信息，返回带明确来源的内容卡片。用户确认后，可创建定时订阅，由服务端根据用户设置进行增量检索、审核、推荐和通知。

## 2. 目标功能

- 对话式一次性知识搜索；
- 在用户授权下参考已有测评兴趣；
- 返回标题、来源、授权摘要和原文链接；
- 生成不涉及敏感推断的推荐原因；
- 用户确认后创建、修改、暂停和删除订阅；
- 服务端定时检索新增内容；
- 内容分类、权利校验、去重、排序和审核；
- App 消息中心和操作系统通知；
- 个性化关闭、非个性化模式和兴趣管理。

## 3. 用户流程

```text
用户发起对话
→ Agent 识别一次性搜索或订阅意图
→ 读取用户授权范围内的兴趣标签
→ 调用白名单搜索工具
→ 权利和安全过滤
→ 返回带来源卡片
→ Agent 生成订阅预览
→ 用户明确确认
→ 业务服务保存订阅
→ 定时任务检索增量内容
→ 分类、去重、审核和排序
→ 消息入库与受控推送
→ 用户反馈形成兴趣调整
```

## 4. Agent 权限

Agent 可以：

- 读取当前用户允许使用的兴趣；
- 调用已授权搜索 Provider；
- 生成查询词、标签、摘要建议和推荐解释；
- 创建订阅预览；
- 提交用户反馈。

Agent 不可以：

- 访问其他用户数据；
- 任意访问互联网或内网；
- 使用平台 Cookie、账号池或逆向接口；
- 直接创建长期订阅而不经用户确认；
- 直接审核通过内容；
- 直接调用推送供应商发送通知；
- 直接执行数据库语句；
- 绕过新闻、版权和未成年人规则。

## 5. 内容来源计划

| 来源 | 首版用途 | 接入方式 | 生产状态 |
|---|---|---|---|
| 万有棱镜自有内容 | 测评、专业、课程、学习内容 | 内部 API | 可开发 |
| 知乎 | 专业体验、学习方法等 | 官方数据开放平台 | 等待授权 |
| 小红书 | 用户主动分享或合作内容 | 分享链接/商务合作 | 搜索默认关闭 |
| 学校、竞赛组织方 | 活动和官方通知 | 书面授权/API/RSS | 逐一批准 |
| 持证新闻供应商 | 教育政策和公共热点 | 商务 API | 等待许可和合作方案 |

## 6. 内容分类

| 类别 | 示例 | 自动推送策略 |
|---|---|---|
| 自有教育内容 | 测评、课程、专业介绍 | 审核后允许 |
| 外部非新闻知识 | 专业体验、学习方法 | 授权允许且审核后推送 |
| 官方通知 | 活动、竞赛报名 | 验证来源、适用范围和有效期 |
| 新闻信息 | 政策、公共事务、突发事件 | 许可明确前禁止公开推送 |
| 高风险内容 | 招生录取、考试、医疗心理、伤害事件 | 强制人工审核或禁止推送 |

## 7. 用户控制

- 一次性搜索不会自动创建订阅；
- 创建或修改订阅需要确认；
- 用户可查看、暂停、修改和删除订阅；
- 用户可关闭个性化推荐；
- 用户可使用非个性化内容模式；
- 用户可查看、修改和删除兴趣标签；
- 用户可对内容反馈“不感兴趣”或举报；
- 用户可关闭某类通知或全部通知；
- 注销时解除设备 Token 并按规则删除个人数据。

## 8. AI 使用

- 境内生产环境优先使用阿里云百炼通义千问；
- 模型通过服务端调用，密钥不进入 App；
- 使用结构化输出；
- 外部内容仅在合同允许 AI 处理时提交模型；
- AI 摘要和生成内容按规定标识；
- 政策、数字、日期、主体和高风险结论需核验；
- 模型无法直接控制数据库、审核和推送。

## 9. 首发边界

首发建议只开放自有教育内容和获得授权的非新闻教育知识。新闻、公共热点和教育政策推送在互联网新闻信息服务许可或持证合作方案取得明确结论后再启用。
