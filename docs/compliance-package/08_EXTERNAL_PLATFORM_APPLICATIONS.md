# 08 外部平台合作申请模板

## 1. 知乎数据开放平台申请

收件邮箱：`openplatform@zhihu.com`  
建议主题：`万有棱镜教育 App 申请知乎搜索与热点数据 API 合作`

正文模板：

```text
您好：

我们是[企业全称]，正在开发“万有棱镜”教育类 App，主要提供学生兴趣探索、专业体验和成长辅助服务。现计划在 App 中增加 Agent 个性化知识检索功能，希望申请知乎数据开放平台的 zhihu_search、global_search、hot_list 等能力。

拟使用场景：
1. 用户主动搜索专业体验、学习方法、大学生活、竞赛和职业发展内容；
2. 根据用户明确订阅的兴趣定时检索新增内容；
3. 在 App 内展示来源、标题、授权摘要和原文跳转；
4. 可能使用阿里云千问进行分类、标签、风险识别和允许范围内的摘要；
5. 可能用于个性化推荐和用户主动开启的通知提醒。

预计用户量：[填写]
预计日调用量：[填写]
上线时间：[填写]

希望确认：
- 接口申请和商务计费方式；
- 允许展示、缓存的字段和期限；
- 是否允许 AI 分析、摘要和 Embedding；
- 是否允许个性化推荐和通知推送；
- 是否允许商业使用；
- 原文跳转、署名、标识和删除同步要求；
- 用户原创内容是否需要另行获得作者授权。

联系人：[姓名/电话/邮箱]
```

## 2. 小红书合作咨询

建议通过小红书企业商务渠道或开放平台工单提交。

```text
我们是[企业全称]，运营“万有棱镜”教育类 App，拟提供学生专业体验、学习方法和校园生活等内容的 Agent 检索与订阅服务。

希望咨询是否存在面向第三方 App 的正式内容搜索、热点趋势或笔记链接数据合作能力，以及以下使用是否可以获得书面授权：
1. 搜索公开笔记或话题；
2. 在第三方 App 展示标题、作者、授权摘要和原文链接；
3. 对授权数据进行 AI 分类、标签或摘要；
4. 用于个性化推荐和用户主动订阅的通知；
5. 缓存期限、商业使用、署名和删除同步要求。

在未取得书面授权前，我方不会使用逆向接口、模拟登录或爬虫批量获取平台内容。
```
