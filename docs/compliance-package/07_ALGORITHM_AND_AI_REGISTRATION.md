# 07 算法自评估与生成式 AI 应用登记准备

## 1. 拟备案/评估能力

| 能力 | 可能算法类型 | 运营主体角色 | 当前状态 |
|---|---|---|---|
| 用户兴趣推荐 | 个性化推送类 | 服务提供者 | 待设计稳定 |
| 内容排序 | 排序精选类 | 服务提供者 | 待设计稳定 |
| 内容搜索与过滤 | 检索过滤类 | 服务提供者 | 待设计稳定 |
| AI 对话、摘要、解释 | 生成合成类 | 应用提供者 | 使用千问，待登记确认 |
| 千问基础模型 | 生成合成类 | 技术支持者为阿里云相关主体 | 获取实时备案证明 |

## 2. 算法机制初稿

### 输入

- 用户主动兴趣；
- 用户授权使用的测评标签；
- 有效阅读、收藏和不感兴趣；
- 订阅主题、来源、频率和屏蔽项；
- 内容标签、时效、质量、来源和风险。

### 候选召回

- 兴趣标签召回；
- 角色/学段召回；
- 订阅关键词召回；
- 编辑精选；
- 适量探索内容。

### 过滤

- 来源和授权；
- 新闻和风险；
- 年龄与适龄；
- 已读和重复；
- 屏蔽主题；
- 过期、撤回和无效链接。

### 排序

```text
interest_match
+ role_stage_match
+ quality
+ freshness
+ source_authority
+ exploration
- seen_penalty
- fatigue_penalty
- risk_penalty
```

### 人工干预与用户控制

- 高风险内容强制人工审核；
- 用户可关闭个性化；
- 提供非个性化模式；
- 用户可查看、修改和删除标签；
- 用户可屏蔽主题和删除订阅；
- 控制来源、主题和观点多样性；
- 设置频率、静默期和疲劳控制。

## 3. 算法自评估报告目录

1. 主体和产品基本情况；
2. 算法名称、类型、应用领域和服务形式；
3. 机制机理和主要流程；
4. 数据来源、质量、标注和个人信息处理；
5. 内容生态和价值导向风险；
6. 用户权益和未成年人保护；
7. 信息茧房、沉迷、差别待遇和操纵风险；
8. 新闻信息、舆论属性和社会动员能力分析；
9. 安全技术、人工干预和应急处置；
10. 监测指标、评测结果和整改；
11. 拟公示算法机制内容；
12. 负责人承诺和附件。

## 4. 生成式 AI 应用登记材料

- 企业营业执照及负责人；
- App 名称、包名、域名和备案号；
- AI 功能说明、截图和测试账号；
- 千问模型正式名称和实时备案号；
- 阿里云服务/合作协议；
- 输入输出数据说明；
- 内容安全和人工审核；
- 投诉、撤回和更正机制；
- 个人信息和未成年人保护；
- AI 显式和隐式标识；
- 安全评估和算法备案情况；
- 服务协议、隐私政策和用户告知。

## 5. 尚待决定

- 推荐算法正式名称；
- 生成合成能力是否单独申报；
- 是否被认定具有舆论属性或社会动员能力；
- 安全评估提交方式和属地联系人；
- 千问具体模型和版本；
- 是否允许用户自由输入开放域问题；
- 是否允许新闻搜索；
- 是否面向不满十四周岁用户。
