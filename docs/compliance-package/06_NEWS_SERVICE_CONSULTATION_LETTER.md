`[企业全称]`（统一社会信用代码：`[填写]`，注册地址：`[填写]`）运营“万有棱镜”教育类移动应用，现拟新增 Agent 个性化知识检索、内容推荐和用户订阅功能。为准确理解并落实互联网新闻信息服务、算法推荐和生成式人工智能服务相关要求，现就拟开展业务进行预咨询。

### 一、现有产品

产品主要提供兴趣探索测评、专业体验、个人报告、学习内容和消息通知，不开放用户新闻采编发布功能。当前 App 备案、ICP 备案及其他资质情况为：`[填写]`。

### 二、拟新增功能

1. 用户通过 Agent 对话表达对专业、学科、竞赛、学习方法或教育话题的兴趣；
2. Agent 调用获得授权的自有或第三方搜索接口，返回标题、来源、授权摘要和原文链接；
3. 用户明确确认后创建定时订阅；
4. 服务端定时检索增量内容，进行权利校验、分类、去重、风险识别、人工审核和个性化排序；
5. 通过 App 消息中心或操作系统通知提醒用户；
6. 用户可关闭个性化、删除兴趣、暂停订阅和关闭通知。

### 三、拟使用来源

- 万有棱镜自有教育内容；
- 知乎官方数据开放平台（待授权）；
- 小红书正式商务合作或用户主动分享链接（未授权搜索默认关闭）；
- 学校、竞赛组织方等授权内容；
- 持证新闻内容供应商（待业务定性和合作确认）。

普通社区内容主要包括专业体验、学习方法和校园生活。涉及教育政策、社会公共事务、突发事件等内容时，系统拟进入独立新闻分类和人工审核流程；在相关许可或持证合作方案明确前，不面向公众推送新闻信息。

### 四、AI 和算法

拟通过阿里云百炼调用已备案的通义千问模型，用于查询理解、分类、标签、风险识别、允许范围内的摘要和推荐解释。用户画像主要来自主动兴趣、已有测评标签和有限行为信号。系统提供关闭个性化和非个性化内容模式。模型无直接审核和推送权限。

### 五、咨询事项

1. 上述功能在何种内容和展示范围内构成互联网新闻信息转载服务或传播平台服务？
2. 仅展示标题、授权摘要和原文跳转链接是否属于互联网新闻信息服务？
3. 使用社区平台内容作为内部趋势信号、最终以权威来源核验，是否需要履行新闻相关许可？
4. 与持证互联网新闻信息服务单位合作时，双方应如何划分服务责任和产品展示边界？
5. 该功能是否属于具有舆论属性或者社会动员能力的互联网信息服务？
6. 应履行哪些算法备案、生成式人工智能应用登记和安全评估手续？
7. 面向未成年人提供上述功能还应落实哪些属地要求？
