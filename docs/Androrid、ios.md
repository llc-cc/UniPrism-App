# 教育类 APP 上线准备清单（深圳企业版｜Android + iOS）

> 适用项目：万有棱镜。
>
> 首发范围：Android 与 iOS 同期准备、开发和上线。
>
> 本文只记录上线前需要准备的材料、办理入口、负责人和最终应取得的结果；代码实现、签名操作、支付接入和提审操作另行整理。

## 0. 文档使用说明

### 0.1 角色定义

| 角色 | 主要责任 |
|---|---|
| 公司负责人 | 确认上线主体、产品名称、业务范围、收费方式和最终审批 |
| 备案经办人 | ICP/APP 备案、公安联网备案、主管部门沟通和材料归档 |
| Apple/应用市场管理员 | 企业账号认证、团队授权、应用记录、商店材料和审核跟进 |
| 产品/运营 | 功能介绍、商品规则、客服、审核说明和商店文案 |
| 法务/合规 | 隐私政策、用户协议、退款规则、未成年人和许可证判断 |
| 设计 | 正式图标、启动页、商店截图和宣传素材 |
| 开发 | 包名/Bundle ID、正式签名公开信息、SDK/权限/域名清单和安装包 |
| 财务 | Apple 协议、税务、收款、微信/支付宝商户和退款结算资料 |

### 0.2 保密规则

普通云文档可以记录：

```text
包名、Bundle ID、Team ID、App Store Apple ID
证书公钥、MD5、SHA-1、SHA-256
备案编号、软著编号、平台应用 ID
公开网址和商店链接
```

普通云文档不得记录：

```text
Android keystore/JKS 原文件和密码
Apple 主账号密码和双重认证验证码
支付私钥、API 密钥和证书密码
服务器 SSH 私钥、数据库密码
公司主账号密码
```

秘密信息统一存入公司密码管理器或加密存储，本文只记录保管人和记录编号。

注意：网站 ICP 备案不等于 APP 备案。如果网站 ICP 不是通过当前阿里云接入办理，而 APP 后台使用阿里云中国内地资源，备案经办人应先向阿里云确认是否需要接入备案。

状态：

```text
✅ 已购买并使用阿里云中国内地服务器
```

上线前需要核验：

- [ ] 阿里云账号已完成企业实名认证

- [ ] 服务器安全组和最小开放端口已核验
- [ ] 日志、监控、告警和应急联系人已准备
- [ ] 生产 API、静态资源和唤醒域名已经确认

建议域名登记：

```text
官网：https://www.uniprism.cn 或公司确认的正式地址
API：https://uniprism.cn 或后端确认的正式地址
静态资源：https://assets.uniprism.cn
APP唤醒：https://link.uniprism.cn（启用后）
```

备案和应用市场只能填写实际部署、真实访问的域名，不能填写尚未启用的示例地址。

## 7. 经营性 ICP、教育资质和其他条件审查

### 7.1 经营性 ICP 许可证

当前业务模式：

```text
免费完成测评
+
付费解锁完整测评报告
```

咨询/办理入口：

- [广东省通信管理局](https://gdca.miit.gov.cn/)

- [ ] 网络安全管理制度

- [ ] 许可证编号和证书（需要时）
- [ ] 对产品和支付方式的限制要求

### 7.2 教育类前置文件

工信部 APP 备案通知指出，从事教育等互联网信息服务且依法需要主管部门审核同意的，备案时需提交相应文件。

准备：

- [ ] 向阿里云备案客服确认申报类目
- [ ] 向深圳/广东相关主管部门确认是否需要前置文件

- [ ] 是否提供课程、培训或教学服务的真实说明

如报告使用生成式 AI、算法推荐、用户画像或自动化决策，公司/法务应结合真实服务方式判断是否涉及额外备案、安全评估、显著提示或用户权利要求。

- [ ] 服务商合同、数据处理和安全条款
- [ ] 法务/合规判断结论

