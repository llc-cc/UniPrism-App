### iOS 三种 ID 的区别和获取顺序

| 名称 | 如何获得 | 项目中的用途 |
|---|---|---|
| Bundle ID | 团队自行确定唯一反向域名，例如候选值 `cn.uniprism.app`，再到 Apple Developer 注册 Explicit App ID | 写入 Xcode 的 `PRODUCT_BUNDLE_IDENTIFIER` |
| Team ID | 公司加入 Apple Developer Program 并审核通过后由 Apple 分配 | 代码签名、证书、描述文件和 Universal Links |
| App Store Apple ID | 在 App Store Connect 创建 App 记录后由 Apple 自动生成数字 ID | App Store 详情页和商店跳转 |

iOS 上线顺序：

1. 公司使用法人主体加入 Apple Developer Program；组织账号通常需要 D‑U‑N‑S 编号、公司域名邮箱和公开网站。
2. 账号通过后，由 Account Holder/Admin 在 Certificates, Identifiers & Profiles 注册 Explicit App ID。
3. Bundle ID 必须与 Xcode `Runner` Target 中的 Bundle Identifier 完全一致。
4. 在 App Store Connect 创建 New App，选择已注册的 Bundle ID；创建后获得 App Store Apple ID。
5. 公司账号把开发协作权限授予开发人员，再由开发配置 Team、证书、描述文件并上传构建。

官方入口：[Apple Developer Program 注册](https://developer.apple.com/help/account/membership/program-enrollment/)、[注册 App ID](https://developer.apple.com/help/account/identifiers/register-an-app-id/)、[创建 App Store Connect App](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app/)。

## 10. 优先顺序

1. 主体、正式名称、服务类目、未成年人范围和收费方式。
2. 正式包名、域名、签名和版本规则。
3. APP 备案、软著、隐私文件和开发者平台账号并行办理。
4. 准备商店素材、审核账号和正式应用包。
5. 真机与隐私合规验收后提交各应用市场。

> 各市场的字段、图片尺寸和资质要求可能调整，正式提交以对应开发者控制台当期要求为准。
