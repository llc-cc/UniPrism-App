# AI 探索课堂功能与验收数据

## 页面入口

- 前端：`http://localhost:5175/#/dialogue-exploration-lab`
- 测试章节：`bnu-math-ch1-set-concept`
- 章节名称：`【北师大必修一·1.1.1】集合的概念与表示`

## 已完成功能

1. 从章节目录创建引导式 AI 课堂，并支持课前寒暄和连续文本对话。
2. 按教学目标执行概念诊断，诊断通过后进入学习方式选择。
3. 支持“多看几个例子、互动探索、概念历史、视频”等学习方式及对应素材。
4. 支持互动素材完成事件，并根据事件推进到理解检查。
5. 支持练习题的思路与答案分别提交、反馈展示和通过/未通过判断。
6. 练习未通过时创建补救分支，展示针对性反馈并提供补救练习。
7. 补救通过后回到主学习路径，继续下一个教学目标并最终完成章节。
8. 左侧历史记录按目标、概念、例子、互动、练习和补救分支展示进度。
9. 点击历史节点可恢复当时的师生对话、完整素材、练习题、作答和反馈。
10. 历史回看为只读模式，显示明确提示，并可一键返回当前学习进度。
11. 当前节点、历史选中节点和完成状态分别展示；失败后正在补救的检测节点不会误标完成。

## 人工验收数据

### 1. G1 概念诊断

输入：

```text
元素要么属于 A（∈），要么不属于 A（∉）。集合元素具有确定性、互异性和无序性。
```

预期：进入学习方式选择。选择“动手判断 ∈/∉”。

### 2. 完成互动素材

按页面题目完成一次正确的 `∈/∉` 判断。

对应事件数据：

```json
{
  "eventType": "SET_MEMBERSHIP_VERIFIED",
  "payload": {
    "element": 3,
    "set": "A",
    "relation": "member"
  }
}
```

预期：进入 G1 理解检查。

### 3. G1 主练习故意答错

练习 ID：`set-same-collection-v1`

思路：

```text
我觉得顺序不同就不是同一个集合。
```

答案：

```text
不是同一个集合
```

预期：进入 `EXTRA_SUPPORT`，左侧出现补救分支，原练习不能显示为已完成。

### 4. G1 补救练习答对

等待页面自动继续，或点击/输入“继续”。补救练习 ID 应为 `set-determinacy-v1`。

思路：

```text
“高个子”没有统一明确的标准，无法确定每名同学是否属于这个整体，违反集合元素的确定性。
```

答案：

```text
不能构成集合
```

预期：G1 变为掌握，进入 G2 概念诊断。

### 5. G2 概念诊断

输入：

```text
列举法适合元素有限且可一一列出的集合，如 {1,2,3}；描述法用 {x|条件} 表示满足共同性质的所有元素，如 {x|x<10,x∈N*}。
```

预期：进入 G2 素材或学习方式选择。若后端沿用 G1 的学习方式，会直接进入素材，此时不要重复选择学习方式。

### 6. G2 练习答对

根据页面实际出现的题型使用其中一组数据。

列举法 `set-roster-v1`：

```text
思路：小于 10 的正整数数量有限，可以逐个列出，所以适合使用列举法。
答案：{1,2,3,4,5,6,7,8,9}
```

描述法 `set-builder-v1`：

```text
思路：描述法用条件描述元素的共同性质，小于 10 的正整数满足 0<x<10 且 x 是正整数。
答案：{x | 0<x<10, x∈N*}
```

预期：当前目标通过；没有其他目标时进入 `GOAL_COMPLETE`。

## 历史画板验收

完成以上步骤后依次点击左侧的例子、互动、练习和补救节点，检查：

1. 画板顶部标题与左侧节点类型一致。
2. 当时的学生输入和 AI 老师回复完整显示。
3. 素材显示完整内容而不是只有标题，且不能再次操作或提交。
4. 练习显示题目、思路、答案、反馈和结果。
5. 页面显示“正在回看历史画板”，点击“回到当前进度”后恢复当前节点。
