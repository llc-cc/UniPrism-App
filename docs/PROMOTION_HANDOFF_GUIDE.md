## 2. 提前确定编号规则

| 字段 | 用途 | 示例 |
|---|---|---|
| `channel` | 推广平台 | `xhs`、`douyin`、`bilibili`、`wechat` |
| `campaign` | 一次推广活动 | `2026_summer` |
| `content` | 具体内容或达人 | `creator_zhang_note_001` |

每个平台、活动、达人和具体内容应有唯一编号，避免上线后无法区分来源。

## 5. 交付前检查

- [ ] 推广链接和二维码在手机上测试通过
- [ ] App 名称、图标、截图和版本为最新正式内容
- [ ] 应用市场地址已真实上线，不使用猜测链接
- [ ] 隐私政策、用户协议和客服地址可访问
- [ ] 数据看板能识别本次活动和内容编号
- [ ] 推广人员已拿到素材、文案、链接、二维码和联系人

不提供给运营：签名文件和密码、服务器或数据库账号、平台主账号、各类密钥和用户原始数据。
